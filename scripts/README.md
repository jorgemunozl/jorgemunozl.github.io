# Scripts

## Notes generation

Note scanning, metadata, graph data, and per-note JSON bodies are generated by **`generate-notes.js`**. Full workflow, folder paths, frontmatter, wiki links, and outputs are documented in the repo root:

**[CONTENT_GUIDE.md](../CONTENT_GUIDE.md)** (section *Notes*).

```bash
npm run generate-notes
```

This writes (among other things) `src/components/data/notesMeta.ts`, `src/components/data/prebuiltGraph.ts`, and `public/notes/<id>.json`.

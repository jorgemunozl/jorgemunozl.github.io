First with region we refer to a set, this set typically is one from $\mathbb{R}^{n}$ and you can define like you want it.

Basically is a region with no holes (under $\mathbb{R}^{3}$) and more generally with no "spaces" I don't know until what point this is similar to a compact set.

Thus you can always connect any two points with a continuous curve, and also you could shrink any closed curve to a point being more precisely continuously shrunk to a point without leaving the region.

>Is Spanish we called to this of set : "conjunto simplemente conexo".

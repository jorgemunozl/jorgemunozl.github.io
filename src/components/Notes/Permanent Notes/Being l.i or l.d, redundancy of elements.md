If a set is l.d for instance, then his elements in one or another way (summing and scaling) are related, you can obtain at least one from the another, in the other hand a set l.i  it's impossible to obtain one element from others.

A l.i set it's a clean form of the l.d set, is like if weren't exist redundancy between the element's.

Now if the set only contains one unique element then is also trivial, the question relies in find a the best version which is the [[Basis Of A Space Vector (Hamel)|basis]].

When you want to compute a [[Vector line integral|line integral]] you care a lot about the path traveled, but if some conditions are followed then you don't care about the path traveled just about the start and final point.

You just evaluate the difference between the "anti-derivative" on that those points, you use the [[Gradient]] of a scalar function, so that scalar function is tied, not with the area, but with the variation of the potential.

And I think that this is pretty because when you evaluate a [[Definite integral - Riemann|definite integral]] you don't care about all the intermediate values, you only work with the endpoints of the set where you want to evaluate the function.

Now the case when you are working with an [[improper integral]] reminds me of the definition of potential that I saw in physics.

We have the all-the-life [[Inner product]] which we represent as $\langle , \rangle$, now if we put a vertical bar |, $\langle u|v \rangle$, we call to $\bra{u}$ **bra** and to $\ket{v}$ **ket**.

Now we think to $\ket{v}$ like a vector also, only to the **ket**. The **bras** are threat it like elements from the [[Dual Space]] [^1].


And it has complete sense because we can create a [[Linear Map]] $f_{v}=\sum\alpha_{i} v_{i}$ that match with the inner product exactly.

I think that we could re define some concepts from this, such as the [[Adjoint Operator]] for that [[Operators are ket bra]].

All the use of this notation comes from the [[Riesz representation theorem]]


[^1]: [[Dirac's bra ket notation]]. pp.8

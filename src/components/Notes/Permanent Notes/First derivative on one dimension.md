>[!tip] Formal Definition
>A function is derivable at a point $c$ that belong to its domain, if exist the follow limit.
>$$f´(x)=\lim_{ x \to c } \frac{f(x)-f(c)}{x-c}$$
>If the function is derivable at all the point in its domain we say that the function is [[continuity idea|derivable]]

From this definition we can easily obtain the first derivatives of the [[Pretty known functions|simples functions]].
Of course it is more difficult obtain the first derivatives of the [[List of special functions|special functions]].

Instead of use the _Cartesian Coordinates_ we use any independent variables that fully describe the system's motion. Pretty seen in [^1]

The classical example is use only an angle to describe a [[pendulum]].

A system with $N$

- A good question[[Degrees of freedom]]

$$
q=(q_{1},q_{2},q_{3},\dots,q_{n})
$$

And the _generalized velocities_

$$
\dot{q}=(\dot{q}_{1},\dot{q}_{2},\dots,\dot{q}_{n})
$$

A graph $G$ (**no-aimed**) is a tuple $(V,A)$ where $V$ (natural numbers) is a finite set of nodes-vertices and $A$ is a set of edges (non ordered pairs).

A man that this is simply amazing.


>[!example]
>$V=\{ 1,2,3 \}$, $A=\{ (1,2),(2,1),(2,3),(3,2) \}$

A **aimed graph** is the same of the first but first here exist arrows. One could go from $A$ to $B$ but not from $B$ to $A$.

>[!definition]
>A [[Real function]] $f$ is called **uniformly continuous** on $A$ if:
>$$ \forall\epsilon>0, x,y\in A, \exists\delta>0,|x-y|<\delta\implies \lvert f(x)-f(y) \rvert <\varepsilon $$

- Think of like if continuous function such that in every point of the domain the steps are regular there are not changes so brutal.
- A [[Uniformly Continuous Function]] is continuous, the other way around is false.

>[!proposition]
>All [[Continuity (One Dimension)|continuous function]] is **uniform** if the set is [[Compactness Set Real]].

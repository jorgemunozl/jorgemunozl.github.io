>[!definition]
>A point $x\in X$ is called interior of a subset $X$ when exist a open interval $(a,b)\subset X$ such that $x\in(a,b)$. [^1]

- To the set of all those points we call $\text{int}$.

>[!definition]
>A set is **open** if $\text{int}(X)=X$.

- This is more important to define the open sets in the reals.
- There exist a close relation with [[Open Set]].  

[^1]: [[Analisis Real Elon Lages]] pp. 65

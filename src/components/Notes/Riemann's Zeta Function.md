>[!definition]
>Let $s$ be a [[Complex Numbers]] then we define the **Riemann's zeta function** [^1]:
>$$\begin{align}\zeta(s)=\sum_{n=1}^{\infty}\frac{1}{n^s}\end{align}$$

- Is clear that is pretty complicated find the values of this function.
- Is a very important number for [[Number theory]].
- [[Riemann Hypothesis]], a quite important result.

[^1]: [[Mathematical Methods for Physicist]] pp.342

Let f be [[Vector function over a real variable]], $f:[a,b]\to \mathbb{R}^{n}$

Let $\varphi:[a,b]\to [c,d]$ [[Real function]], and [[Homeomorphism in Topology]].

A reparameterization of $f$, is a [[composition]] $\hat{f}=f  \circ \varphi$, such that $\hat{f}:[c,d]\to \mathbb{R}^{n}$. Introducing the new parameter $\tau \in[c,d]$, $\hat{f}(\tau)=(f\circ \varphi)(\tau)$ the reason of the name.

It's easy to see that using the [[Chain rule real functions]].

$$
\hat{f}'(\tau)=f'(\varphi(\tau))\cdot \varphi'(\tau)
$$

When $\varphi$ is a linear function they only differ for a constant scalar. In another cases they differ for a variable scalar, but always is a multiple of the original vector. 

And we could think on velocity using not only the linear function but also the quadratic, and a whole family of functions with the only condition that they are [[Homeomorphism in Topology]] .

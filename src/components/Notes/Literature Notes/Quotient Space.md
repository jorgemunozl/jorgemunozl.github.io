We can create a [[Equivalence Relation]] on a [[Vector Space]], $V$, for this we have to define a [[Sub Vector Space]], $S$.
$$
u,v \in V , u \sim v \text{ if } (u-v )\in S $$
Thus we can define a [[Equivalence Class]] ,$[v]=\{ u \in V| u \sim v \}= v+S$. Think of like a line, define by $v$.

>[!definition]
>Thus we can create a [[Quotient Set]] with $V$ and $S$ , $\frac{V}{S}=\{ [v] \  | \ v \in V \}=\{ v+S \ | \ v \in V \}$ [^1].

- Think of like all the possible lines, so we can perfectly create a vectors space with all those lines!

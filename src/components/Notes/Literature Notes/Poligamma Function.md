This function is the generalization of the [[Digamma Function]]. Instead of take only the first logarithmic derivative, you generalize and takes the $m-th$ derivative, like follow.

>[!tip] Poligamma Function
$$\begin{align}\psi^{m}(x)=\left( \frac{d}{dx} \right)^{m+1}\ln(\Gamma(x))\end{align}$$

Now what then? When you generalize, doors that were previously closed open.

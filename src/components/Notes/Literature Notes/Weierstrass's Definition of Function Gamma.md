>[!proposition]
>Let $z$ be a complex number then the [[Gamma Function]] of $z$ is:
>$$\begin{align}\Gamma (z)=\frac{e^{-\gamma z}}{z} \prod_{n=1}^{\infty} [ (1+\frac{z}{n})^{-1} e^{\frac{z}{n}} ] \end{align}$$
Where $\gamma$ is the [[Euler-Mascheroni Constant]].

- From this form, we can prove the [[Euler's Reflection Formula]] using the
- [[Weierstrass Factorization Theorem]] for the sin.

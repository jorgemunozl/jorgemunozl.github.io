>[!definition]
>Let $R$ be a [[Binary Relation]] over a set $S$, $R$ is called **partial** **order** if is reflexive, anti-symmetric and transitive. [^1]

- Now we ask this specific requirements, and how we relate to the name.
- When we apply the **partial** **order** over the set, we say that the set is **partially ordered**
- If not exist ambiguity at the moment to compare two elements of the set we say that the set $S$ is totally ordered, linearly ordered, a chain. So here it could be exist ambiguity. [[Well ordered set]]

[^1]: [[Topologia de los espacios metricos]] pp. 13

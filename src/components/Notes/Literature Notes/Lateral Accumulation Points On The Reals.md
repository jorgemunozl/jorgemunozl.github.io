>[!definition]
> $a$ is a accumulation point by the left of the set $X$, $a\in X^{'}_{+}$ when: [^1]
>$$ \forall\varepsilon>0,X\cap(a,a+\varepsilon )\neq \emptyset $$ 

- The second way to see it is using using [[Accumulation Point - Real|accumulation point]]. For that you create a set $Y=X\cap(a,+\infty)$ and if $a$ is **an ordinary accumulation point**.
- The third way is using [[Sequence]]. If exist a sequence $x_{n}>a$ such that $x_{n}\in X$ then $a$ is one of them.
- Now there also exist the **bilateral accumulation points**. When $a\in X'_{+}\cap X'_{-}$.



[^1]: [[Analisis Real Elon Lages]] pp. 86

>Let $\mathbf{E}$ be the **embedding matrix** which shape is [[Embedding dimension]] times the [[Vocabulary - Tokenizer]]. $\mathbf{E}\in \mathbb{R}^{d\times \mathbf{v}}$.

- This matrix is obtained by training it, each column represents a word (token).
- For instance ChatGTP-3 has tokens 50.257. And has like **Embedding Dimension** 12,228 giving = 617,558,016 parameters.

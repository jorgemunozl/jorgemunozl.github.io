>[!definition]
> The **expected value** is a map from the space function the the reals, $\mathbb{E}:\mathcal{F}\to \mathbb{R}$ using a [[Random variable (univariate)|random variable]] $X\sim p(x)$ like base[^1], this is:
>$$ \mathbb{E}_{X}[g(x)]=\int_{X}g(x)p(x)dx$$

- Is clear that in the discrete case is a sum.
- Answer to the question, which is the the most probable number that a function will return give a variable
- This is a **linear** map since that both integral and sum are **linear**, but is important to realize where are you integrating or the index of the sum.


[^1]: [[Mathematics for Machine Learning]] pp. 193

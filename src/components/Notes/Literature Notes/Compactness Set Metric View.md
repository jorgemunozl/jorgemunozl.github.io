>[!definition]
>A **cover** of $X$ is a family $\mathcal{U}=\{ A_{i} \}_{i\in I}\subset \mathcal{P}(X)$ such that $X=\bigcup_{i\in I}A_{i}$[^1].
>If $A_{i}$ is [[Open Set]] for all $i$, then is a **open cover**.

>[!definition]
>A **sub-cover** of a **cover** is a subfamily that also covers $X$. If this is **finite** we talk about **finite sub-cover**.

>[!definiton]
> A [[Metric Space]]  is **compact** if **every open cover has a finite sub-cover**.

- Think of like if you want to fill $X$ and for that you have subset.
- The [[Borel Lebesgue Theorem]]
- [[Compactness Set Real]]

[^1]: [[Topologia de los espacios metricos]] pp. 101

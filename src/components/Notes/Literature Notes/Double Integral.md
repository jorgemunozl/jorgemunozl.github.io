>[!definition]
>Let $f:\mathbb{R}^{2}\to \mathbb{R}$ be a [[Scalar function]] , if is defined over $C$, then the double integral is defined as [^1].
>$$
\iint \limits_{C} f(x,y)dA=\lim_{ \lVert P \rVert  \to 0 }\sum_{k=1}^{N}f(x_{k}^{*},y_{k}^{*})A_{r_{k}}  $$
>when the limit exist. If exist we say that $f$ is **integrable** over $C$.

- When the function is different from one we say that represents a volume.
- The formal definition is based on the concept of [[Partition for a one dimension function|Partition]].
- In the [[Double Integral Resolution|practice]] the region is is defined is the most important, we don't care a lot about the form of the function. 

[^1]: [[Analisis Matematico III Calculo Vectorial]]

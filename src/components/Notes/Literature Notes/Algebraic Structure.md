An algebraic structure represents a space where we can use operations with elements of a non empty set. 
This operators obey a list of [[Math Axioms]].

>[!note] We use n-th tuples for denotate algebraic structure
>For example $(G,\chi$, $\eta$,$\cdots$,$\beta$) with $G$ a nonempty set, if we create a finite list of axioms we can say that that tuple is an algebraic structure.

We already know certain Algebraic Structure.

>[!example]
>- Groups
>- Rings
>- Field
>- Vector Space
>- Algebra

Is the set of all the [[Equivalence Class]] formed by a [[Binary Relation]] on a set $S$.

>[!definition]
>Let $S$ be a set and $\sim$ a equivalence relation. The quotient set is $S / \sim$ is: [^1]
> $$ S / \sim=\{ [a] | \ a \in S \}$$

- It is very useful study a set by its classes rather than element by element.
- It's like we partitioned to the original set. 
- For that reason establish a [[Equivalence Relation]] it is the same of give a [[Partition]]

[^1]: [[Topologia General]]  pp.19

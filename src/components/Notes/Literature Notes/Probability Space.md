- The **sample space** is notated as $\Omega$ is actually a set of all the possible events. What an events means? Of course that you first need to define an environment.

- Now the **event space**, how the name says, is a set of all the subsets of $\Omega$ notated as $\mathcal{A}$, a element of this space is defined by one sentence, normally referencing to a certain features of the nature of the elements.

- The **probability** $P$ which is a function $P:\mathcal{A}\to[0,1]$, which is a measure of belief that a event happen.

With this three we define the [^1] **probability space** a three tuple $(\Omega,\mathcal{A},P)$. Which is the mathematical object that necessary should be exist when we work with probabilities, but in  practical we actually never reference to this, we use the notion of  [[Random variable (univariate)]].

- Now the way how the **event space** behaves is interesting, since in when $\Omega$ is continuous is related with the [[borel σ algebra]]

[^1]: [[Mathematics for Machine Learning]] pp. 181

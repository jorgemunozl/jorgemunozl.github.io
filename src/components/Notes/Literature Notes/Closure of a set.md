>[!definition]
>Give it a [[Metric Space]] the **closure of a set is** defined like the union of the set and its [[Derivative of a set]]. This is the set and all its **accumulation points** together.  [^1]
>$$\bar{A}=A\cup A'$$

 - The closure reflects a set and its boundary, is like give it a plus to the set, is to adhere point that are very near to the set.
- We call **sticking point** to the elements of this set.
- Important to define [[Close Set]].

**Ref**. [[Topologia de los espacios metricos]]

[^1]: [[Topologia de los espacios metricos]] pp. 33

>[!definition]
>Let $f:\mathbb{R}^{n}\to \mathbb{R}$ be a [[Scalar function]], $H_{f(x)}=[h_{ij}]_{n\times n}$ the **Hessian** **matrix** of $f$ evaluated on the point $x_{0}\in Dom(f)$, where [^1] 
> $$h_{ij}=\frac{\partial f^{2}}{\partial x_{i}\partial x_{j} }=\frac{\partial }{\partial x_{i}}\left( \frac{\partial f}{\partial x_{j}} \right)$$

-  We are using the notation seen on [[Superior Order Partial Derivatives]].
- To work with this is very natural to talk about the [[Definiteness of the matrix]]
- Now we could say that the matrix is [[Symmetric matrix]] if the second derivative is continuous by [[Clairaut's Theorem]].
- Is very useful when proving the [[Sylvester Criterion]]
- And with this we could introduce [[Taylor's Polinomial on more dimensions]].
- There is some interesting matters with it. [^2]

[^1]: [[Analisis Matematico III Calculo Vectorial]]

[^2]: [[Deep Learning]] pp.  103

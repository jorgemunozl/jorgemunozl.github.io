>[!theorem]
>Any [[Orthogonal operator]] written in a proper [[Basis Of A Space Vector (Hamel)]] in [[Euclid Vector Space]] have the form of Rotations, Identity or Reflections [^2].

- Thus we know all the form of the rotations in $\mathbb{R}^{n}$.
- We can use this trick in the [[Polar Descomposition]].
- Now there exist a special property, (special for me), if I have the [[Characteristic Polynomial]] and I want to reconstruct the Orthogonal operator from it? In the $\mathbb{R}^{3}$case you find the imaginary values using **Ruffini**, then from those you can actually find the form of the matrix.

[^1]: [[Linear Algebra Done Right]] pp. 257
[^2]: [[Linear Algebra and Geometry Manim]] pp. 147

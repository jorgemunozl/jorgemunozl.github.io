A matrix $A$ is called Jordan's Block is have the form

>[!note] Jordan Block
>$$A=\begin{pmatrix}
\lambda &1 &0 &\cdots& 0\\
0 &\lambda &1 &\cdots& 0 \\
0 &0 &\lambda & \cdots& 0 \\
\vdots &\vdots &\vdots &\ddots& 1 \\ 
0 &0&0&\cdots &\lambda\end{pmatrix}$$

or directly is _diagonal_.

The dimension of the matrix doesn't care much, only this have to be a _square matrix_.

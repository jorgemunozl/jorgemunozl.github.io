>[!definition]
>Give it a [[Metric Space]] $(X,d)$, let $A\subset X$ be a subset it's called **open**, if for each $a\in A$, exist $r_{a}>0$ (that depends only of a) such that $B(a,r_{a})\subset A$ 
>This is:
>$$
\forall a\in A, \exists \ r_{a}>0,B(a,r_{a})\subset A$$

- If we choose any point at the set and exist a real number $r$ such that the respective [[Open , closed balls and spheres|open ball]] it is include on the set then the set is ___open.___  

- Is pretty know the concept of open when we talk about real set. But the generalization is pretty and necessary.

- From the [[Topology I don't care about the geometry]] view talk of opens set is very important, normally to the elements of $A$ we call opens.

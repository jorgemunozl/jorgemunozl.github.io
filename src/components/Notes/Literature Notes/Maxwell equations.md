The Maxwell equations give us all what we want to know about electromagnetism. They can be reduced into four equations. (Two if using the [[Electromagnetic Tensors]]).

First you discover the **integral forms** and then using calculus and some clever definitions you can obtain the **differential forms**.

The integral forms comes from experiments, the another ones can be derived using the [[Gauss Divergence Theorem]].

|  Integral Form   |  Differential Form   |
| --- | --- |
|   [[Gauss Law]]: $$\oint \vec{E}\cdot d\vec{A}=\frac{q}{\varepsilon_{0}}$$   |  [[First Maxwell Equation differential form]]   |
| It doesn't exist mono magnetic poles: $$\oint \vec{B}\cdot d\vec{A}=0$$ |  | 
| [[Faraday Law Induction]] : $$\oint\vec{E}\cdot d\vec{s}=-\frac{d\Phi_{B}}{dt} $$|  |
| [[Ampere Maxwell Law]]: $$\oint\vec{B}\cdot d\vec{s}=\mu_{0}I+\varepsilon_{0}\mu_{0}\frac{d\Phi_{E}}{dt} $$ | |

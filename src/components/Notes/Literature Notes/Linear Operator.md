>[!definition]
>If a [[Linear Map]] takes a elements of a space and transform it to another element in that same space, not another [[Vector Space]], we call it **linear operator**. [^1]

Let $V,W$ be two vectors space over the same field.

- Let $Hom(V,W)$ the set of linear maps in such a way: $T:V\to W$.
- To the set $Hom(V,V)$ and have inverse we call $Aut(V)$.
- To the set $Hom(V,V)$ and not necessary have inverse we call $End(V)$.
- $(Hom(V,W),+,\cdot)$ form a [[Vector Space]] called **vector space of homomorphisms**. Also another way to notated is $\mathcal{L}$.

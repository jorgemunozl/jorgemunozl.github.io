>[!definition] 
> Let $(G,g)$ be a group, if for all $a, b \in G$,if the following holds:$$
>\begin{align} g(a,b)=g(b,a) \end{align}$$
>Then we call the group **abelian** [^1].

-  If a [[Group]] satisfies the axiom of __commutativity__, we call it an Abelian Group.
- Although it is necessary because in the list of axioms never mention the commutativity.
- The name "**Abelian**" honors to the great mathematician Niels Henrik Abel.

An binary operation acts on a set in such a way that domain and co-domain are the same. It takes two elements from the set and [[Map like the generalization of a function|map]] them to another element within the set. This in mathematical language:

>[!tip] Formalize 
>Let $S$ be a binary operation that acts in the non empty set $B$, then:
>$$\begin{align}
>S: B \times B \rightarrow B \end{align}$$

We need to mention that this is an operator, it return a set element, don't confuse with a **Binary** **Relation**.

>[!definition]
>Let $T$ be a [[Linear Operator]], $\lambda \in \mathbb{F}$ is called **eigenvalue** if exist $v\in V$ such that: [^1]
>$$T(v)=\lambda v$$

- If $v=0$, then the equation becomes trivial and a nonsense, so we avoid it.
- Work with the _linear operator_ ($T-\lambda I$) [[Matrix - Linear Transformation Idea|matrix form]] is more practical, for resolve the equations.
- How the [[Kernel of Linear Map|kernel of that operator]] is not only the zero (or at least we want that), the follow equation its true.
 $$\det(T-\lambda I)=0$$
- Now the nature of this values depends exclusively on the [[Vector Space]], specifically of the [[Field]].
- We care about this values because [[eigen descomposition]].


[^1]: [[Linear Algebra Done Right]] pp. 134

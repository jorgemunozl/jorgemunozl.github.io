Let $(S,\leq)$ be a [[Partially Ordered Set]]. We are gonna to use the [[Equivalence Relation]] that we establish to order the set $S$. Notice that order in the bigger sense.

>[!definition]
>$S$ partially ordered set, $\xi$ is: [^1]
>1. Mayor e. if $\forall \eta \in S: \eta \leq \xi$ 
>2. Maximum e. if $\forall \eta \in S: \xi \leq \eta\implies n=\xi$  (maximal pues)
>3. Minimum e. if $\forall \eta \in S:  \eta \leq \xi \implies n=\xi$  (minimal , 2 lo explica mejor)
>4. Minus e. $\forall \eta \in S: \xi \leq \eta$.

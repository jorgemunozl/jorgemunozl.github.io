A **Dedekind cut** divides the set of rational numbers Q\mathbb{Q}Q into two non-empty sets AAA and BBB such that:

- Every element of AAA is less than every element of BBB.
- AAA has no greatest element.
- AAA is non-empty and not equal to Q\mathbb{Q}Q.

The real number is identified with the lower set AAA.

**Example:** The square root of 2 is represented by the set:

A={x∈Q:x2<2 or x<0}A = \{ x \in \mathbb{Q} : x^2 < 2 \text{ or } x < 0 \}A={x∈Q:x2<2 or x<0}

This set "cuts" the rationals where 2\sqrt{2}2​ would be.

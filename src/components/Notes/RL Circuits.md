If you have a [[Resistors]] and a [[Inductors]], first we don't reach to the maxima [[Current Intensity]] at the instant, because that is what **Inductors** make.

So using the [[Kirchhoff Law]] we obtain:

$$
\varepsilon_{0}+\varepsilon_{L}-IR=0
$$
Where the first term comes from the constant [[Electromotive Force]].

Then using definitions you obtain: 

That the current is like:

$$
i(t)=\frac{\varepsilon}{R}(1-e^{ -t/\tau })
$$

Where $\tau$ is equal to $\frac{L}{R}$

With it you can find the respective voltages for each component by replacing.

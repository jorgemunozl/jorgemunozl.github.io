>[!definition]
>Give it a [[random variable]] $X$ which is continuous (necessarily it should to be modeled by a continuous function?) we define the **cumulative distribution function** as (for uni-variate): [^1]
>$$
P(a\leq X\leq b)=\int_{a}^{b}f(x)dx $$
>The multivariate case is clear that you need to define each uni-variate in the same manner 

[^1]: [[Mathematics for Machine Learning]]

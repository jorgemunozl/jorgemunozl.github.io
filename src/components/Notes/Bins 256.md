Okay, let's say that we have a real number $x$, and I want to take this real number into a discrete ID. Integer, why would you make that?

On computer science we are interested on work with numbers between 0 and 256.

How this works? Let's say that you have a finite set of numbers: Then it has a **max value** and **min value**. We partition that set such that if a number fall in a subset, this real number correspond to a integer.

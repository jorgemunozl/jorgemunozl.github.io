In the most basic case when we have a set of real numbers with $(card=n)$, we can easily compute the mean $(\sigma^{2})$ and from that we can create another number such that:
$$
	\sigma^{2}=\sum \lvert x-\overline{x} \rvert^{2} \frac{1}{n} 
$$
We call it variance $(\sigma^{2})$. Now what does this number mean?
The deviation $(\sigma)$ is a measure that tell how dispersed is our data, if all our data is the same (zero dispersion) then deviation is equal to zero, now if our our data is spread (in the extremes) then this number is big.
